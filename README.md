# جرس الحصص — نسخة iOS (`Jaras for iOS`)

نسخة iOS أصلية (Native Swift & SwiftUI) لتطبيق **«جرس الحصص»**، مصممة لتقديم نفس تجربة أندرويد بأقصى ما يتيحه نظام iOS 16.2+ و iOS 17+.

---

## كيف يحقق التطبيق نفس التجربة على iOS؟

يتكون المشروع من **٣ أهداف برمجية (Targets)** تعمل معاً:

1. **التطبيق الرئيسي (`Jaras`)**:
   * **الربط مع تقويم Google (`EventKit`)**: يقرأ الحصص من تقويم Google المتزامن على الآيفون ويرقّمها تلقائياً بحسب ترتيبها في اليوم (`الحصة الأولى`، `الحصة الثانية`...).
   * **الثيم الأخضر الزمردي والوضع الداكن الافتراضي**: نفس التدرج الأخضر (`#047857` ← `#059669` ← `#10B981`) مع إمكانية التبديل للوضع الفاتح من الإعدادات.
   * **النافذة المنبثقة الكاملة (`AlertOverlayView`)**: الجرس الأخضر ثلاثي الأبعاد مع ميدالية وزارة التعليم، وموجات الصوت، وكبسولة `📖 | بـدء`، و`الحصة الثانية`، والقوس الذهبي، وزر `حاضر، أنا جاهز!` (بدون الساعة وبدون مؤقت داخل النافذة).

2. **امتداد النافذة المنبثقة فوق التطبيقات (`JarasNotificationContent`)**:
   * لأن iOS يمنع النوافذ العائمة التقليدية، يستخدم التطبيق **`UNNotificationContentExtension`** مع تنبيهات **`Time-Sensitive`**.
   * عندما يرن الجرس قبل الحصة بـ ٣ دقائق وأنت داخل أي تطبيق آخر (مثل YouTube أو Safari)، يظهر التنبيه في الأعلى بصوت الجرس (`bell.wav`)، وعند سحبه للأسفل تفتح **بطاقة الجرس الأخضر المتحرك ثلاثي الأبعاد وكبسولة الحصة بالكامل** فوق التطبيق المفتوح دون الخروج منه!

3. **مؤقت الـ ٣ دقائق وشريط التقدم بنمط تطبيقات التوصيل (`JarasWidget` — Live Activity & Dynamic Island)**:
   * بمجرد إغلاق النافذة المنبثقة (أو الضغط على `حاضر، أنا جاهز!`)، ينطلق **النشاط الحي (Live Activity)** في **الجزيرة التفاعلية (Dynamic Island)** وعلى **شاشة القفل**:
     * يعرض عداداً تنازلياً حياً للثواني (`٠٢:٥٩`) وشريط تقدم (`ProgressView`) يمتلئ تدريجياً من `0%` إلى `100%` تماماً مثل تطبيقات توصيل الطلبات.
   * عند انتهاء الـ ٣ دقائق: يختفي المؤقت تلقائياً ويصدر إشعار بسيط بصوت الجرس: **«بدأت الحصة الآن · بالتوفيق والنجاح!»**.

## طريقة بناء ملف `Jaras.ipa` وتثبيته على الآيفون

### الخيار الأول: من ويندوز مباشرة (عبر GitHub Actions + Sideloadly / AltStore)
1. ارفع مجلد `jaras-ios` إلى مستودع GitHub خاص أو عام.
2. سيعمل ملف البناء التلقائي `.github/workflows/build-ipa.yml` على خادم `macos-14` لتوليد مشروع Xcode وبناء ملف **`Jaras.ipa`**.
3. حمّل `Jaras.ipa` من قسم **Artifacts** وثبّته على الآيفون باستخدام **Sideloadly** أو **AltStore**.

### الخيار الثاني: على جهاز Mac (عبر Xcode)
```bash
brew install xcodegen
xcodegen generate
open Jaras.xcodeproj
```
اختر حسابك في **Signing & Capabilities** ثم اضغط **Run (`⌘R`)** لتثبيته مباشرة على الآيفون.
